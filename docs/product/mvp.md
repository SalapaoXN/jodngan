# MVP Scope

## Must Have
- User account and authentication.
- Course creation and management.
- Notes-speed task capture with task name and due date; course is optional.
- Estimated effort and importance can be added later without blocking task creation.
- A deterministic, explainable recommendation for what to work on next.
- Remaining-time display and detection of supported deadline/workload risk.
- A lightweight Today view showing upcoming work and current recommendations.

## Nice to Have Later
- Notifications.
- Calendar integrations.
- AI natural-language commands.
- Team or group-project features.
- Advanced analytics.

## Explicit Non-Goals for MVP
- Microservices.
- Kubernetes.
- Event-driven architecture without a concrete need.
- Real-time collaboration.
- Building a custom authentication protocol.
- Making AI responsible for core scheduling correctness.

## MVP Success Criteria
A user can capture a task almost as quickly as writing it in Notes, immediately see time remaining, and get an explainable, repeatable recommendation. Planning quality improves when the user adds effort information later, but incomplete optional data never blocks task capture.
