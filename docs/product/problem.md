# Problem Definition

## Pain Point
Students often have assignments, projects, and exams with overlapping deadlines. Existing tools can record tasks and dates, but students still have to manually decide what to start first, how much time each task needs, and whether the current plan is realistic.

## Working Assumptions
- Students frequently manage multiple deadlines at the same time.
- Deadline alone is not enough to determine what should be done next.
- Estimated effort and available time materially affect priority.
- A useful system should reduce manual planning, not add another place to maintain duplicate information.

## Current Alternatives
- Calendar apps: good at showing dates, weak at workload prioritization.
- Todo apps: good at tracking tasks, usually require manual ordering.
- Flexible workspace tools: powerful but often depend on users designing their own planning system.

## Proposed Value
JodNgan combines deadline, estimated effort, priority, and available time to recommend a practical work order and surface schedule conflicts.

## Validation Status
This is currently assumption-driven and based on personal experience plus lightweight competitor reasoning. Formal user research is intentionally deferred to keep the portfolio project moving.

## Key Question
Can JodNgan make the answer to "What should I work on next?" meaningfully easier and more reliable than a manually maintained task list?
