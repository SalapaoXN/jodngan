# Primary User Flow

## Goal
A student should be able to capture a new assignment with nearly the same effort as writing it in a phone note, then immediately see useful planning information.

## Flow A: Quick Capture
1. Open JodNgan.
2. Tap or focus the quick-add field.
3. Enter task name.
4. Set due date.
5. Optionally select course.
6. Save.
7. JodNgan immediately shows time remaining and an initial recommendation.

## Flow B: Progressive Enrichment
When more precision is useful, the user can later add:
- Estimated effort
- Importance
- Preferred work time
- Notes or subtasks

These fields should improve planning quality but should not block initial capture.

## Flow C: Daily Decision
The main view should answer these questions quickly:
- What is due soon?
- How many days/hours remain?
- What should I work on next?
- Is anything at risk of being late?

## Design Direction
Prefer a lightweight task list with strong deadline/status cues over a dashboard full of charts. Complexity should stay behind the interface whenever possible.
